# E-Commerce Sales Analysis & Interactive Dashboard

> **Turning raw sales data into actionable business insights using Excel, VBA, and data visualization.**

## 📊 Project Overview

This project presents an end-to-end **E-Commerce Sales Analysis** developed in Microsoft Excel. The objective was to transform raw sales data into a structured analytical dataset and build an interactive dashboard to evaluate **sales performance, profitability, customer behavior, product performance, and regional trends**.

The project demonstrates practical application of **data cleaning, automation, lookup techniques, pivot-based analysis, KPI development, and dashboard storytelling**.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — Data analysis, formulas, tables & dashboard development
- **VBA** — Data cleaning and process automation
- **VLOOKUP** — Data mapping and information retrieval
- **Pivot Tables** — Aggregation and multidimensional analysis
- **Pivot Charts** — Interactive data visualization
- **KPI Analysis** — Performance measurement and business insights

## 🔄 Data Preparation & Cleaning

The raw dataset was transformed into an analysis-ready structure using Excel and VBA.

Key activities included:

- Cleaning and organizing raw data
- Removing unnecessary fields
- Structuring data using Excel Tables
- Automating cleaning tasks using VBA
- Using VLOOKUP for data mapping and enrichment
- Preparing the dataset for Pivot Table and dashboard analysis

## 📈 Business Analysis

The dashboard was designed to answer key business questions such as:

- How are sales performing over time?
- Which products and categories generate the highest sales?
- Which regions contribute the most to revenue?
- How does profitability vary across products and categories?
- Which areas represent stronger or weaker performance?
- How are key performance indicators changing over time?

## 📊 Dashboard & Insights

The interactive dashboard combines **KPIs, Pivot Charts, trend analysis, comparisons, and performance breakdowns** to provide a consolidated view of e-commerce business performance.
